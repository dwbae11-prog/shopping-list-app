# 🛒 쇼핑 리스트 앱

살 물건을 적어두고 체크하거나 지울 수 있는 아주 간단한 웹 앱이에요.
브라우저에 내장된 저장 공간(localStorage)에 목록을 저장해서, 창을 닫았다가 다시 열어도 목록이 그대로 남아있어요.

## 사용한 기술

- **HTML** (`index.html`) — 화면의 뼈대 (입력창, 버튼, 목록)
- **CSS** (`style.css`) — 화면을 예쁘게 꾸며주는 스타일
- **JavaScript** (`script.js`) — 물건을 추가/체크/삭제하는 실제 동작

## 실행 방법

별도의 설치 과정 없이, `index.html` 파일을 웹 브라우저로 열기만 하면 바로 사용할 수 있어요.

## 기능

- ➕ 물건 이름을 입력하고 목록에 추가하기
- ✅ 체크박스를 눌러서 산 물건 표시하기
- ✖️ 필요 없는 물건을 목록에서 지우기
- 💾 새로고침하거나 브라우저를 다시 열어도 목록이 그대로 저장되어 있기
